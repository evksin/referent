# Дорожная карта развития приложения

## Текущие возможности

- ✅ Парсинг статей с URL и загрузка файлов
- ✅ Генерация краткого описания статьи
- ✅ Извлечение тезисов
- ✅ Создание постов для Telegram
- ✅ Генерация иллюстраций к статьям
- ✅ Копирование результатов
- ✅ Адаптивный дизайн

---

## Приоритет 1: Критические улучшения

### 1.1 История обработки

**Описание:** Сохранение истории обработанных статей в localStorage или базе данных.

**Преимущества:**

- Быстрый доступ к предыдущим результатам
- Возможность повторной обработки
- Сравнение результатов

**Реализация:**

- LocalStorage для клиентского хранения
- Опционально: база данных (SQLite/PostgreSQL) для серверного хранения
- UI: боковая панель или вкладка "История"

### 1.2 Экспорт результатов

**Описание:** Возможность экспортировать результаты в различные форматы.

**Форматы:**

- Markdown (.md)
- PDF (через библиотеку jsPDF или puppeteer)
- DOCX (через библиотеку docx)
- JSON (для программного использования)
- Прямая отправка в Telegram (через бота)

**Реализация:**

- Кнопки экспорта под блоком результата
- Серверные API routes для генерации файлов

### 1.3 Настройки качества и стиля

**Описание:** Пользовательские настройки для генерации контента.

**Настройки:**

- Длина результата (краткий/средний/подробный)
- Стиль изложения (формальный/неформальный/технический)
- Язык результата (русский/английский/другие)
- Температура AI (креативность)
- Модель AI (выбор между разными моделями)

**Реализация:**

- Модальное окно или боковая панель настроек
- Сохранение в localStorage
- Передача параметров в API

## Приоритет 2: Расширенные функции

### 2.1 Пакетная обработка

**Описание:** Обработка нескольких статей одновременно.

**Возможности:**

- Загрузка списка URL (по одному на строку)
- Загрузка нескольких файлов
- Выбор типа обработки для каждого элемента
- Прогресс-бар для отслеживания
- Экспорт всех результатов одним файлом

**Реализация:**

- Новая страница или вкладка "Пакетная обработка"
- Очередь задач на сервере
- WebSocket или polling для обновления статуса

### 2.2 Сравнение статей

**Описание:** Сравнение нескольких статей по темам, тезисам, стилю.

**Возможности:**

- Выбор 2-5 статей для сравнения
- Генерация сравнительного анализа
- Визуализация различий и сходств
- Таблица сравнения тезисов

**Реализация:**

- Новая страница "Сравнение"
- Специальный промпт для AI с анализом нескольких статей
- UI с таблицами и графиками

### 2.3 Шаблоны промптов

**Описание:** Предустановленные и пользовательские шаблоны для разных типов контента.

**Шаблоны:**

- Новостной пост
- Технический обзор
- Образовательный материал
- Резюме для презентации
- Пользовательские шаблоны

**Реализация:**

- База шаблонов в конфигурации
- UI для создания/редактирования шаблонов
- Применение шаблона при генерации

### 2.4 Улучшенная генерация иллюстраций

**Описание:** Расширенные возможности для работы с изображениями.

**Функции:**

- Выбор стиля иллюстрации (реализм, аниме, 3D, и т.д.)
- Настройка параметров генерации (размер, детализация)
- Генерация нескольких вариантов
- Редактирование промпта для изображения
- Сохранение истории иллюстраций

**Реализация:**

- Расширение UI для настроек иллюстраций
- Параметры в запросе к AI Horde
- Галерея сгенерированных изображений

## Приоритет 3: Интеграции и автоматизация

### 3.1 Интеграция с Telegram

**Описание:** Прямая отправка результатов в Telegram.

**Возможности:**

- Настройка Telegram бота
- Выбор канала/чата для отправки
- Автоматическая отправка после генерации
- Планирование публикаций

**Реализация:**

- Telegram Bot API
- Настройки в профиле пользователя
- Кнопка "Отправить в Telegram"

### 3.2 RSS-фид мониторинг

**Описание:** Автоматическая обработка новых статей из RSS-лент.

**Возможности:**

- Добавление RSS-лент
- Автоматическая проверка новых статей
- Фильтрация по ключевым словам
- Автоматическая генерация постов

**Реализация:**

- Парсинг RSS (библиотека rss-parser)
- Cron-задачи или серверные воркеры
- Настройки в профиле

### 3.3 API для внешних приложений

**Описание:** REST API для интеграции с другими сервисами.

**Эндпоинты:**

- `POST /api/v1/process` - обработка статьи
- `GET /api/v1/history` - история обработок
- `GET /api/v1/status` - статус обработки
- `POST /api/v1/batch` - пакетная обработка

**Реализация:**

- API ключи для аутентификации
- Документация (Swagger/OpenAPI)
- Rate limiting

### 3.4 Интеграция с Notion/Obsidian

**Описание:** Экспорт результатов в популярные системы заметок.

**Возможности:**

- Прямой экспорт в Notion
- Создание страниц в Obsidian
- Сохранение с правильным форматированием

**Реализация:**

- Notion API
- Локальное сохранение для Obsidian
- Кнопки экспорта
